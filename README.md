# Venkatrao Thallapalli Portfolio

Production-ready React + Tailwind CSS portfolio site for an AI/ML Engineer profile.

## Stack

- React (Vite)
- Tailwind CSS
- Lucide React icons

## Run Locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Replace Placeholder Assets

- Resume: replace `public/resume/Venkatrao_Thallapalli_Resume.pdf`
- Open Graph image: replace `public/images/og-cover.svg`
- Project visuals: replace files under `public/images/projects/`

Keep the same file names if you do not want to update code references.
